# Вариант №1871303

Разработать веб-приложение на языке Java с использованием Spring Boot, реализующее сервис заявок.

Предметная область: библиотека.

Основной объект системы: событие.

Пользовательская роль: менеджер.

Обязательный сценарий: оформление заказа.

Система хранения типа «ключ — значение»: Etcd.

## Дополнительные параметры

- сценарий временного хранения: временная заявка;
- сценарий кэширования: настройки пользователя;
- атомарный механизм: счётчик просмотров объекта;
- исследование поведения системы: конфликт параллельных записей.

## Требования к программе

1. Развернуть систему хранения, указанную в варианте.
2. Реализовать подключение к ней из Java/Spring Boot.
3. Выбрать и обосновать способ представления данных в модели «ключ — значение».
4. Реализовать хранение части данных приложения в выбранной системе.
5. Реализовать механизм временных данных: TTL для Redis, application-level expiration для Riak KV или lease для Etcd.
6. Реализовать кэширование часто запрашиваемых данных.
7. Реализовать назначенный атомарный счётчик, ограничение запросов или блокировку.
8. Настроить сохранение и восстановление данных, если выбранная система поддерживает этот механизм.
9. Исследовать назначенный сценарием режим поведения системы.
10. Сделать выводы о применимости выбранного хранилища для разработанного приложения.
